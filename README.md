## Управление таблицами

### Установка

```bash
pip install primitive-db
```

### Запуск

```bash
database
```

### Команды

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу. `ID:int` добавляется автоматически, если не указан. |
| `list_tables` | Показать список всех таблиц. |
| `drop_table <имя>` | Удалить таблицу. |
| `help` | Справка. |
| `exit` | Выход. |
| `insert into <таблица> values ("значение1", значение2, ...)` | Добавить запись. `ID` генерируется автоматически, его **не** передают. Строки — в кавычках, `int` и `bool` — без. |
| `select from <таблица>` | Показать все записи таблицы. |
| `select from <таблица> where <столбец> = <значение>` | Показать записи по условию. |
| `update <таблица> set <столбец> = <значение> where <столбец> = <значение>` | Обновить записи по условию. |
| `delete from <таблица> where <столбец> = <значение>` | Удалить записи по условию. |
| `info <таблица>` | Показать схему таблицы и количество записей. |

Поддерживаемые типы: `int`, `str`, `bool`.

### Пример

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".

>>>Введите команду: info users

## Обработка ошибок и подтверждение действий

- **Автоматическая обработка ошибок.** Все операции с БД обёрнуты в декоратор `handle_db_errors`: `FileNotFoundError`, `KeyError` (нет таблицы/столбца), `ValueError` (валидация типов) перехватываются и выводятся понятным сообщением. Незапланированные ошибки тоже не роняют программу.
- **Подтверждение опасных операций.** `drop_table` и `delete` спрашивают подтверждение:
  ```
  Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]:
  ```
  Любой ответ, кроме `y`, отменяет операцию.
- **Замер времени.** `insert` и `select` печатают время выполнения:
  ```
  Функция select выполнилась за 0.002 секунд.
  ```
- **Кэширование `select`.** Повторный одинаковый `select` возвращает результат из кэша; кэш сбрасывается после `insert`/`update`/`delete`.
```
